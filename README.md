## 📌 주요 경험 및 관심 분야

- 🏗 **Spring Boot 기반 REST API 서버 설계 및 구현** — Reel Trip API 서버를 처음부터 직접 설계, Spring Security + JWT 인증 구조 구축
- 🔐 **인증/인가 아키텍처** — JJWT 기반 토큰 인증, Spring Security 적용
- 🗃 **MyBatis 기반 SQL 매핑 설계** — 복잡한 쿼리를 동적 SQL로 직접 제어하는 영속성 계층 구성
- 🧠 **AI 연동 백엔드** — pgvector를 활용한 벡터 검색 기반 추천/검색 기능 설계
- 🔄 **DB 스키마 버전 관리** — Flyway로 마이그레이션 이력 관리
- 📦 **모노레포 환경에서의 백엔드 운영** — Turborepo 기반 Web/Mobile/API 통합 구조에서 API 서버(Maven, Docker) 독립 관리
- 🔧 **ERP/MES 실무** — 저장 프로시저 디버깅, SQL 최적화, MES ↔ ERP 시스템 간 데이터 동기화
- 🧱 **레거시(C#/.NET, MSSQL)와 모던 스택(Java/Spring Boot, PostgreSQL)을 함께 다루는 경험**
- 📑 **API 문서화** — SpringDoc OpenAPI(Swagger)로 API 스펙 공유 및 협업
