## 📌 주요 경험 및 관심 분야

- 🏗 **RESTful API 설계 및 백엔드 아키텍처 구축** — ERP/MES 연동, 재고 동기화 등 실무 백엔드 로직 개발
- 🔧 **저장 프로시저(Stored Procedure) 디버깅 및 SQL 최적화** — MSSQL, PostgreSQL 기반
- 🔄 **시스템 간 연동(Integration)** — MES ↔ ERP 데이터 동기화, 멀티 백엔드 서비스 Nginx 라우팅 구성
- 🧠 **시스템 설계 및 확장 가능한 서비스 구조**에 대한 관심
- 🧱 **레거시 시스템과 모던 프레임워크를 함께 다루는 경험** — C#/.NET, Java/Spring Boot 병행
- 📦 **개인 프로젝트(Reel Trip)에서 백엔드 리드** — Spring Boot API 서버 설계 및 구현, Turborepo 모노레포 구조 관리
- 🤖 **AI 연동 백엔드 경험** — pgvector, OpenAI API를 활용한 벡터 검색 기반 서비스 설계
