# 👋 안녕하세요, 안재경(Jaekyoung Ahn)입니다

- 💻 **F1soft 솔루션사업팀**에서 고객사 ERP/MES 백엔드(Java)와 신규사업 모바일 백엔드 API(C# .NET Core)를 함께 담당하고 있습니다
- 🧩 프레임워크 없는 순수 서블릿+JDBC 코드베이스에서 기존 로직을 읽고, 최소 변경으로 안전하게 고치는 데 익숙합니다
- 🔄 서로 다른 시스템(MES ↔ 더존 ERP 등)이 비동기로 연동될 때 발생하는 데이터 정합성 문제를 진단·대응한 경험이 있습니다
- 🚀 개인 프로젝트에서는 기획부터 배포까지 풀스택으로 직접 설계·구현합니다 (백엔드 프레임워크 마이그레이션, 인증 구조 설계, 외부 API 연동 포함)
- 📑 확인 안 되는 내용은 미확인으로 남기고, 코드와 다른 부분은 있는 그대로 적는 **사실 기반 문서화**를 원칙으로 합니다
